# Panduan belajar

1. Mulai Bab 1–7 secara berurutan; baca tujuan dan contoh, kerjakan dry run, lalu coba program.
2. Buka Python Studio dari kode tugas. Isi STDIN satu jawaban per baris. Runtime membutuhkan internet; hanya jalankan kode yang dipercaya.
3. Untuk praktikum offline, unduh ZIP bab, ekstrak seluruh berkas, lalu jalankan python nama_file.py dari folder tersebut.
4. Gunakan Lab dinamis dan Flowchart Builder. Diagram adalah alat penyusunan langkah, bukan interpreter flowchart.
5. Kerjakan kuis bab dan Assessment Center; 210 variasi numerik berasal dari 35 pola. UTS/UAS adalah latihan mandiri, bukan ujian kampus.
6. Tandai materi dan praktikum selesai. Selesaikan kuis untuk lencana. Backup data di Study Tools sebelum menghapus cache browser.
