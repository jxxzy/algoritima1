BAB 06

Perulangan dan game tebak angka

Pilih for atau while, jaga keadaan loop, dan pastikan pengulangan dapat berhenti.

TUJUAN BELAJAR

Telusuri iterasi, akumulator, sentinel, break, continue, dan loop bersarang; bedakan jumlah iterasi dari nilai data.

↻
01

for untuk rentang, while untuk kondisi

Inisialisasi, kondisi lanjut, pembaruan, dan akumulator harus terlihat.

for cocok untuk rentang atau kumpulan yang diketahui. range(1, 6) menghasilkan 1 sampai 5 karena batas akhir tidak disertakan. Inisialisasi total sebelum loop; jika total dibuat di dalam loop, hasil iterasi sebelumnya hilang.

while mengevaluasi kondisi sebelum badan loop. Tiga unsur diperlukan: keadaan awal, kondisi melanjutkan, dan perubahan keadaan. Tanpa kemajuan menuju berhenti, loop dapat berjalan selamanya.

WHILEsisa = 3; while sisa > 0: print(sisa); sisa -= 1FORfor i in range(1, 6): print(i)
↪

break menghentikan loop terdekat; continue melewati sisa iterasi lalu kembali mengevaluasi kondisi. Keduanya tetap membutuhkan alur yang mudah dilacak.

Sentinel adalah nilai khusus untuk berhenti. Nilai -1 diperiksa sebelum rentang data, sehingga tidak masuk total atau pencacah. Nilai 0 tetap sah; percabangan if skor saja akan salah mengenainya.

02

Game tebak angka dan loop bersarang

Penghitung, status menang, dan batas percobaan harus konsisten.

Contoh rahasia 7 dengan tiga percobaan. Setiap tebakan yang berhasil dikonversi menambah penghitung sekali, termasuk tebakan di luar rentang pada versi dasar. Setelah tebakan benar, set status menang lalu gunakan break agar tidak meminta tebakan berikutnya.

Python · game tebak angka
rahasia = 7
batas = 3
percobaan = 0
menang = False
while percobaan < batas:
    tebakan = int(input("Tebak 1-10: "))
    percobaan += 1
    if tebakan == rahasia:
        menang = True
        break
print(f"Percobaan: {percobaan}")
if not menang:
    print(f"Jawaban: {rahasia}")

Loop bersarang menjalankan loop dalam untuk setiap iterasi loop luar. Segitiga setinggi empat memiliki panjang baris 1, 2, 3, dan 4, total 10 angka. Gunakan batas baris + 1 pada loop dalam agar angka baris ikut dicetak.

!

Untuk akumulasi skor, total dan jumlah diperbarui hanya untuk data valid. Sentinel -1 tidak ditambahkan dan tidak menambah pencacah.

↗

Praktikum, tantangan, dan evaluasi

Catat keadaan setelah setiap iterasi, lalu buktikan loop berhenti.

Praktikum membangun pencatat nilai hingga sentinel -1. Tolak skor di luar 0–100; hitung jumlah valid, total, dan rata-rata. Sentinel dan data ditolak harus tetap terpisah.

Enam tantangan

  1. Gunakan for untuk menjumlahkan 1 sampai 10.
  2. Buat segitiga bintang setinggi n positif.
  3. Pastikan tebakan di luar 1–10 tidak menghabiskan kesempatan.
  4. Tambahkan jumlah nilai lulus tanpa mengubah sentinel atau validasi.
  5. Ubah satu aturan pencatat nilai lalu bandingkan versi lama dan baru.
  6. Trace satu uji batas segitiga dan tambahkan uji penolakan baru.

Pengembangan menambahkan jumlah nilai lulus dengan batas lulus 60 tanpa mengubah urutan sentinel dan validasi. Uji normal, batas, penolakan, dan regresi harus dijalankan lagi.

Evaluasi formatif
  1. for digunakan untuk iterasi batas/kumpulan diketahui; while untuk kondisi yang dapat berubah.
  2. Sentinel adalah sinyal berhenti dan bukan data.
  3. Invariant akumulasi memastikan total dan jumlah selalu berasal dari himpunan data valid yang sama.
  4. Program perlu cabang data kosong agar pembagian rata-rata tidak dilakukan dengan nol.
  5. Dalam loop, break menang atau continue menolak secara terkontrol.
