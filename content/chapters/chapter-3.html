01

Variabel menyimpan makna, bukan hanya nilai

Nama yang jelas membantu memilih operasi yang benar.

Variabel adalah nama yang merujuk ke suatu objek. suhu = 30 membuat nama suhu merujuk angka 30; penugasan berikutnya dapat mengubah nilai yang dirujuknya. Python peka huruf besar-kecil. Gunakan nama yang menyebut satuan seperti jarak_km.

Input selalu bertipe str. Teks "2" + "3" menghasilkan "23". Konversi keduanya menjadi integer untuk memperoleh 5. Jangan gunakan bool("tidak"): string apa pun yang tidak kosong bernilai True.

Konversi tipe dengan sengaja

Input → konversi → hitung
teks = input("Masukkan jumlah: ")
jumlah = int(teks)
total = jumlah + 3
print(total)  # Masukan 12 menghasilkan 15

Gunakan int untuk jumlah benda, float untuk ukuran yang mungkin pecahan, str untuk nama/NIM/kode pos, dan bool untuk status yang sudah ditafsirkan dengan aturan eksplisit.

02

Konversi Celsius, Fahrenheit, dan Kelvin

Jaga rumus, tipe, dan batas fisik suhu.

FAHRENHEITF = C × 9 / 5 + 32KELVINK = C + 273.15
Python · konversi suhu
celsius = float(input("Suhu Celsius: "))
if celsius < -273.15:
    print("Suhu di bawah nol mutlak.")
else:
    fahrenheit = celsius * 9 / 5 + 32
    kelvin = celsius + 273.15
    print(f"Fahrenheit: {fahrenheit:.2f}")
    print(f"Kelvin: {kelvin:.2f}")
0°C → 32°F · 273.15 K100°C → 212°F · 373.15 K−40°C → −40°F · 233.15 K−273.15°C → 0 K

Program menolak suhu di bawah nol mutlak (−273.15°C), batas yang ditambahkan pada latihan. Format .2f hanya mengatur tampilan dua desimal; nilai numerik untuk perhitungan tidak berubah.

03

Pecah durasi dan jarak dengan // serta %

Pembagian bulat menghitung unit penuh; modulo mengambil sisa.

/Pembagian biasa135 / 60 = 2.25
//Pembagian bulat135 // 60 = 2 jam
%Sisa pembagian135 % 60 = 15 menit
Python · menit menjadi jam dan sisa
menit = int(input("Durasi (menit): "))
if menit < 0:
    print("Durasi tidak boleh negatif.")
else:
    jam = menit // 60
    sisa_menit = menit % 60
    total_detik = menit * 60
    print(f"{jam} jam {sisa_menit} menit")
    print("Total detik:", total_detik)
    print("Periksa:", jam * 60 + sisa_menit)
↺

Invariant / pemeriksaan balik: jam × 60 + sisa_menit harus sama dengan menit awal. Untuk 135, 2 × 60 + 15 = 135. Nilai sisa selalu antara 0 dan 59.

Konversi jarak mengikuti pola sama: untuk 2.345 meter, 2345 // 1000 = 2 km dan 2345 % 1000 = 345 m.

04

Kecepatan rata-rata: satuan harus cocok

Ubah waktu ke jam sebelum membagi kilometer.

KONVERSI WAKTUwaktu_jam = waktu_menit / 60KECEPATANkm/jam = jarak_km / waktu_jam
Python · hitung kecepatan
jarak_km = float(input("Jarak (km): "))
waktu_menit = float(input("Waktu (menit): "))

if jarak_km < 0 or waktu_menit <= 0:
    print("Jarak harus >= 0 dan waktu > 0.")
else:
    waktu_jam = waktu_menit / 60
    kecepatan = jarak_km / waktu_jam
    print(f"Kecepatan: {kecepatan:.2f} km/jam")

Dry run: 15 km dalam 30 menit → waktu 30/60 = 0,5 jam → kecepatan 15/0,5 = 30 km/jam. Jarak nol sah jika waktunya positif; waktu nol ditolak sebelum pembagian.

!

Membagi kilometer langsung dengan menit menghasilkan km/menit, bukan km/jam. Angka bisa tampak masuk akal, tetapi label satuannya keliru.

Praktikum terbimbing: konverter kegiatan

  1. Buat tabel Celsius, Fahrenheit, dan Kelvin untuk semua data uji.
  2. Uji mengganti float(input()) dengan input(); jelaskan mengapa operasi matematis gagal pada string.
  3. Buat berkas terpisah untuk mengubah kilometer menjadi meter; contoh 1,25 km menjadi 1.250 m. Program studi kasus sebaliknya mengubah meter menjadi kilometer dan sisa meter.
  4. Bedakan kesalahan format (teks bukan angka) dan kesalahan rumus atau satuan.
  5. Tetapkan kontrak input valid, output, pesan penolakan, serta fitur pengembangan.
  6. Lakukan dry run normal dan batas sebelum mengetik.
  7. Implementasikan versi terkecil lalu tambah fitur bertahap dengan menjaga regresi.
  8. Uji penolakan dan catat input pemicu serta hasil sebelum/sesudah perbaikan bug.

Tantangan bertingkat

  1. Dasar: konversikan menit bulat menjadi detik.
  2. Menengah: pecah 135 menit menjadi 2 jam 15 menit dengan // dan %.
  3. Lanjut: tolak suhu Celsius di bawah −273,15; uji nilai tepat di batas dan sedikit di bawahnya.
  4. Pengembangan: konversikan meter menjadi kilometer dan meter sisa; pisahkan nama peserta dari variabel pengukuran.
  5. Adaptasi durasi: input menit bulat tidak negatif dan tampilkan jam/sisa; bandingkan versi awal dengan versi pengembangan yang juga menampilkan detik dan pemeriksaan balik.
  6. Pembuktian kecepatan: ubah menit ke jam sebelum menghitung km/jam; gunakan jarak nol sebagai uji batas sah dan waktu nol sebagai uji penolakan.
Pembahasan dan hasil uji semua tantangan 1–6
  1. Menit ke detik: detik = menit × 60; 135 menit menjadi 8.100 detik; 0 diterima, nilai negatif ditolak.
  2. Jam dan sisa: 135 // 60 = 2 dan 135 % 60 = 15; hasilnya 2 jam 15 menit. Tidak menggunakan pembulatan pembagian biasa.
  3. Nol mutlak: −273,15°C diterima sebagai batas dan menghasilkan 0 K; −273,16°C ditolak.
  4. Jarak: 2.345 m menjadi 2 km 345 m dengan // 1000 dan % 1000; identitas nama tetap terpisah. Program tambahan mengubah 1,25 km menjadi 1.250 m.
  5. Durasi: pengembangan menambah total detik dan pemeriksaan balik tanpa mengubah 135 menit → 2 jam 15 menit. Invariant: jam * 60 + sisa == menit.
  6. Kecepatan: 0 km dalam 20 menit sah dan menghasilkan 0 km/jam. 10 km dalam 0 menit ditolak sebelum pembagian.

Studi kasus mandiri dan kunci analisis

Kasus: konverter membaca menit bulat tidak negatif, menghasilkan jam, sisa menit, detik total, dan rekonstruksi. Pengembangan menambah jarak meter ke kilometer dan sisa meter.

  1. Tujuan: membantu peserta/panitia membaca durasi dan jarak kegiatan dalam unit yang sesuai.
  2. Urutan: parse dan validasi → jam = menit // 60 → sisa = menit % 60 → detik → rekonstruksi → kilometer dan sisa meter → tampilkan.
  3. Data: nama berupa teks; menit dan meter berupa integer. Identitas tidak dicampur ke besaran yang dihitung.
  4. Trace: `Rani`, 135 menit, 2345 m → 2 jam 15 menit, 8100 detik, balik 135, 2 km 345 m.
  5. Batas: nol diterima; 59/60/61 menghasilkan 0:59, 1:00, 1:01. Nilai negatif ditolak. Nilai maksimum tidak ditentukan soal; integer Python dibatasi memori.
  6. Regresi: durasi 135 menit tetap menjadi 2 jam 15 menit; versi baru menambah detik, pemeriksaan balik, dan jarak.

Evaluasi: input bertipe str; / adalah pembagian biasa, // pembagian bulat. Periksa durasi dengan jam * 60 + sisa == menit. Format .2f tidak mengubah nilai hitung. Bandingkan konverter Celsius dan durasi: sama-sama mengonversi input sebelum hitung, tetapi tipe dan operasi berbeda. Uji batas 59/60/61 menangkap kesalahan penggunaan pembagian biasa untuk durasi.

Jawaban evaluasi formatif dan refleksi (1–9)
  1. input() selalu menghasilkan str, termasuk ketika pengguna mengetik angka.
  2. / menghasilkan pembagian biasa (dapat berupa pecahan); // mengambil hasil bulat ke bawah.
  3. Periksa dengan jam * 60 + sisa == menit, 0 <= sisa < 60, dan detik == menit * 60.
  4. .2f mengatur tampilan dua desimal, bukan mengubah nilai numerik yang dihitung.
  5. Pada −273,15°C, Kelvin tepat 0 dan input diterima. Kondisi di bawah konstanta nol mutlak menentukan penolakan.
  6. Durasi negatif ditolak sebelum hasil dibuat; bukti uji adalah pesan penolakan dan tidak ada output konversi.
  7. Suhu dan durasi sama-sama parse input sebelum menghitung. Suhu memakai float dan rumus skala; durasi memakai int, //, dan %.
  8. Kesalahan rawan adalah menggunakan / atau round() untuk durasi. Kasus 59, 60, dan 61 menit menguji batas unit secara langsung.
  9. Dipahami: hasil pembagian bulat dan modulo dapat diperiksa dengan rekonstruksi. Perlu dipelajari: presisi floating-point pada suhu/kecepatan.

Hubungannya: tipe dan konversi Bab 3 memakai urutan dan keputusan dari Bab 2 serta kontrak IPO Bab 1. Batas contoh: durasi/jarak berupa integer; program tidak menyimpan data peserta secara permanen.
